contain original Guardian Tales resources and prepared bootstrap data. Those

The content snapshot combines the preserved Android 3.57.0 Google Play European
installation dated 2026-11-16, its Japanese voice supplement, and local download
archives assembled from those resources. It includes prepared matching static
table responses and catalogs for the implemented local backend. Two Spanish
word-filter files are newline-only local placeholders, not official data.

The content release excludes the APK, recovered IL2CPP metadata, account saves,
guest credentials, provider tokens, SDK user caches, TLS private keys and emulator
images. It does not include the official server implementation. Its resource
coverage is limited to the preserved snapshot described in the
[offline content guide](offline-content.md#what-this-release-preserves).

Release manifests and SHA-256 checksums identify the published bytes. A passing
integrity check establishes that an import matches the release; it does not
establish complete regional coverage or backend functionality.
